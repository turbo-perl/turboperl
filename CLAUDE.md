# Working in this repository

## Commits and pushes

Do not commit or push without an explicit instruction to, such as "commit"
or "commit and push".  Saying which branch work belongs on is not one.

An instruction covers the work it was given for.  Detailed instructions
for a larger piece of work (for example, "commit and push as you go")
cover that piece of work only, and end with it.

Once work is ready, say so and ask, rather than committing it.
